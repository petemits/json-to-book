**Short answer:** Yes — it still uses your computer’s hardware resources.

Here’s how it works when you **boot a computer from a USB drive** (Linux, Windows-To-Go, etc.):

### ✅ **What resources come from the USB?**
- The **operating system (OS) files** are stored on the USB.
- Programs and system files **load from the USB** instead of the internal SSD/HDD.

### ✅ **What resources come from your computer?**
Even though the OS is on the USB, the computer *still uses*:

- **CPU (processor)**  
- **RAM (memory)**  
- **Graphics (GPU)**  
- **Motherboard / power system**  
- **Keyboard, screen, Wi-Fi, Bluetooth**  
- **Internal SSD/HDD** (only if you choose to access them)

### 🧠 Think of it like this:
Booting from USB is like bringing your own “portable OS,”  
**but you are still borrowing the computer’s brain, memory, and muscles.**

### ⚠️ Important:
Booting from USB does **NOT** increase your RAM.  
It also does **NOT** bypass hardware limits.  
It only changes *where the OS loads from*, not the computer’s specs.

### Example:
If your laptop has:
- 4GB RAM  
- i5 CPU  

Even if you boot Ubuntu from USB, the OS still has only:
- 4GB RAM  
- the same i5 CPU

# ⚡ **Why RAM is extremely fast**
RAM connects directly to the CPU through a **very high-speed channel** called the memory bus.

Speed comparison:

| Device | Speed |
|--------|--------|
| **RAM (DDR4/DDR5)** | 15,000–30,000 MB/s |
| SSD | 500–3,500 MB/s |
| USB | 20–400 MB/s |
| HDD | 50–150 MB/s |

The system uses **virtual memory** (swap/page file):

- Windows uses disk or USB for ReadyBoost  
- Linux uses swap space  
- macOS uses compressed memory + SSD

That’s why upgrading RAM gives the biggest performance improvement.

- 16GB  
- 32GB  
etc.

If your laptop has **8GB**, it may be:
- One 8GB stick  
- Two 4GB sticks
