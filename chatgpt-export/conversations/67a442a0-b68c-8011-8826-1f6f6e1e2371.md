---

### **1. Create a Telegram Bot**
1. Open Telegram and search for **BotFather**.
2. Send the command:  
   ```
   /newbot
   ```
3. Follow the instructions to:
   - Choose a bot name.
   - Choose a unique username (must end with `bot`).
   - Get the **bot token**.

---

### **2. Set Up a Web Server**
You need a web server to host your mini-app. You can use:
- **Flask/Django (Python)**
- **Express.js (Node.js)**
- **PHP, Ruby, or any other backend framework**
- Host on **Heroku, Vercel, Firebase, or AWS**

---

### **3. Create the Web App**
Telegram Web Apps are regular web pages but include **Telegram’s JavaScript SDK** for integration.

#### **Basic HTML Example**
```html
<!DOCTYPE html>
<html>
<head>
    <title>Telegram Web App</title>
    <script src="https://telegram.org/js/telegram-web-app.js"></script>
    <script>
        let tg = window.Telegram.WebApp;
        tg.expand(); // Expands the WebApp to full screen
    </script>
</head>
<body>
    <h1>Welcome to My Mini App!</h1>
    <p>User: <span id="user"></span></p>
    <script>
        document.getElementById("user").innerText = tg.initDataUnsafe.user?.first_name || "Guest";
    </script>

</html>
```
- `telegram-web-app.js` gives access to Telegram features.
- `tg.expand();` ensures the app is fullscreen.

## **3. Create the Web App (Flask)**
This will be the **Mini App (Web App)** running inside Telegram.

### **Flask Web App**
Create a file **`app.py`**:
```python
from flask import Flask, render_template, request, jsonify
import openai  # For AI responses

app = Flask(__name__)

# OpenAI API Key (Replace with yours)
openai.api_key = "your_openai_api_key"

@app.route("/")
def index():
    return render_template("index.html")

@app.route("/ask", methods=["POST"])
def ask():
    data = request.json
    user_input = data.get("message", "")

    # AI response using OpenAI GPT
    response = openai.ChatCompletion.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": user_input}]
    )
    
    reply = response["choices"][0]["message"]["content"]
    return jsonify({"reply": reply})

if __name__ == "__main__":
    app.run(debug=True)
```

### **HTML for Web App (`templates/index.html`)**
```html
<!DOCTYPE html>
<html lang="en">
<head>
    <title>Telegram AI Chatbot</title>
    <script src="https://telegram.org/js/telegram-web-app.js"></script>
</head>
<body>
    <h1>Ask me anything!</h1>
    <input type="text" id="user_input" placeholder="Type your message">
    <button onclick="sendMessage()">Ask</button>
    <p id="response"></p>

    <script>
        function sendMessage() {
            let userInput = document.getElementById("user_input").value;
            fetch("/ask", {
                method: "POST",
                headers: { "Content-Type": "application/json" },
                body: JSON.stringify({ message: userInput })
            })
            .then(response => response.json())
            .then(data => {
                document.getElementById("response").innerText = data.reply;
            });
        }
    </script>
</body>
</html>
```
- This **mini app** asks AI questions and gets responses.

### **Creating a Text-to-Image AI Bot in Telegram Using Telebot**  
This bot will take text input from a user in Telegram and generate an AI image using **DALL·E** (OpenAI) or another AI model.

## **3. Write the Telegram Bot Code**  
Create a Python script **`bot.py`**:  

```python
import telebot
import openai

# Replace with your API keys
BOT_TOKEN = "your_telegram_bot_token"
OPENAI_API_KEY = "your_openai_api_key"

bot = telebot.TeleBot(BOT_TOKEN)
openai.api_key = OPENAI_API_KEY

# Command to start the bot
@bot.message_handler(commands=["start"])
def send_welcome(message):
    bot.send_message(
        message.chat.id, 
        "Welcome! Send me a text description, and I'll generate an AI image."
    )

# Handle text messages
@bot.message_handler(func=lambda message: True)
def generate_image(message):
    user_text = message.text
    bot.send_message(message.chat.id, "Generating image... Please wait ⏳")

    try:
        response = openai.Image.create(
            prompt=user_text,
            n=1,
            size="1024x1024"
        )
        image_url = response["data"][0]["url"]
        bot.send_photo(message.chat.id, image_url, caption="Here is your AI-generated image!")
    except Exception as e:
        bot.send_message(message.chat.id, f"Error: {str(e)}")

# Start bot polling
bot.polling()
```

```python
import telebot
import requests
import time

# Telegram bot token
BOT_TOKEN = "your_telegram_bot_token"
bot = telebot.TeleBot(BOT_TOKEN)

# Choose API (Hugging Face, Replicate, or Local Stable Diffusion)
USE_HUGGING_FACE = True  # Set to False if using Replicate or local
HUGGING_FACE_API = "https://api-inference.huggingface.co/models/stabilityai/stable-diffusion-2"
HUGGING_FACE_KEY = "your_huggingface_api_key"

REPLICATE_API = "https://api.replicate.com/v1/predictions"
REPLICATE_KEY = "your_replicate_api_key"

LOCAL_SD_API = "http://127.0.0.1:7860/sdapi/v1/txt2img"

# Function to generate images
def generate_image(prompt):
    headers = {"Authorization": f"Bearer {HUGGING_FACE_KEY}"}
    data = {"inputs": prompt}
    
    response = requests.post(HUGGING_FACE_API, headers=headers, json=data)
    
    if response.status_code == 200:
        return response.json()[0]["url"]  # Hugging Face returns an image URL
    else:
        return None

# Handle text messages
@bot.message_handler(func=lambda message: True)
def handle_message(message):
    bot.send_message(message.chat.id, "Generating image... Please wait ⏳")
    
    image_url = generate_image(message.text)
    
    if image_url:
        bot.send_photo(message.chat.id, image_url, caption="Here is your AI-generated image!")
    else:
        bot.send_message(message.chat.id, "Failed to generate image. Try again later.")

# Start bot polling
bot.polling()
```
