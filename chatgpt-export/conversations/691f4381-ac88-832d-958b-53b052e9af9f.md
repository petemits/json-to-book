# ✅ **How a Hologram LED Fan Projector Works**
A hologram fan is NOT a real hologram.  
It’s a **high-speed spinning LED bar** that uses **persistence of vision (POV)** to make a floating 3D image in the air.

### **Main Components**
1. **High-speed BLDC motor**
2. **LED strip (RGB LEDs) mounted on spinning blades**
3. **Microcontroller (STM32, ESP32, or custom)**
4. **Gyro sensor (keeps stability)**
5. **Power supply (12–24V, usually DC adapter)**
6. **Frame + Safety cage (important!)**
7. **Software that converts video → LED timings**

Because the LEDs spin very fast (~700–1200 RPM), your eyes blend the light into a floating image.

# ✅ **Simple DIY Version (Beginner Project)**  
This is the simplest version you can build with basic electronics.

### **You Need**
- ESP32 development board  
- Small brushless DC motor (drone motor)  
- ESC (Electronic Speed Controller)  
- 5V or 12V power supply  
- WS2812B LED strip (individually addressable LEDs)  
- 3D-printed or wooden blade to mount LEDs  
- Balance weights  
- Arduino IDE (for programming ESP32)

### **Steps**
---

## **1. Build the Rotating Blade**
Make a **lightweight blade** (~20–30 cm long) that will spin.

Attach **WS2812B LED strip** (20–60 LEDs) along the blade.

---

## **2. Install Motor + ESC**
Mount the brushless DC motor on a base.

Connect:
```
Motor → ESC → Power supply
ESC signal → ESP32 PWM pin
```

---

## **3. ESP32 Controls LED + Motor**
The ESP32 will:
- spin the motor at constant speed  
- light the LEDs at precise angles to form images  

You’ll use timing instead of angle sensors in the beginner version.

---

## **4. Upload POV Display Code**
You can use open-source code like:

🔎 **GitHub search:** “ESP32 POV display WS2812B”  
(There are complete builds.)

This code converts text/images to LED frames.

---

## **5. Calibrate RPM**
The clearer the image, the more stable the speed:

**Most builds run 900–1200 RPM**.

---

## **6. Test With Simple Patterns**
Start with:
- a circle  
- simple text (“HELLO”)  
- rotating shapes  

Once stable → try 3D animations.

# ✅ **Advanced (Real Commercial-Style 3D Hologram Fan)**  
A professional-style version requires:

### **Components**
- High torque BLDC motor  
- 4-blade LED arms (individually addressable)  
- STM32 microcontroller  
- Gyroscope (MPU6050)  
- LED driver ICs  
- CNC aluminum frame  
- Video preprocessing software

### **Tech Used**
✔ PWM control  
✔ Fast SPI signaling to LED drivers  
✔ Frame interpolation to generate 3D images  
✔ SD card or WiFi upload  
✔ Custom firmware for pixel mapping  

This level is more complex but fully doable with engineering knowledge.
