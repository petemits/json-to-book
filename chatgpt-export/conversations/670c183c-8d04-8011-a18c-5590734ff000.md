Here is a Python script that searches for files in a specific directory on Windows based on a given date range. It uses `os` to navigate the file system and `datetime` to filter files by their creation or modification date.

```python
import os
from datetime import datetime

def find_files_in_date_range(directory, start_date, end_date):
    # Convert the start_date and end_date to datetime objects
    start_date = datetime.strptime(start_date, '%Y-%m-%d')
    end_date = datetime.strptime(end_date, '%Y-%m-%d')

    # List to store files found in the date range
    files_in_range = []

    # Walk through the directory
    for foldername, subfolders, filenames in os.walk(directory):
        for filename in filenames:
            filepath = os.path.join(foldername, filename)

            # Get file's modification time
            file_mod_time = os.path.getmtime(filepath)
            file_mod_datetime = datetime.fromtimestamp(file_mod_time)

            # Check if the file modification time falls within the range
            if start_date <= file_mod_datetime <= end_date:
                files_in_range.append(filepath)

    return files_in_range

# Example usage
directory_to_search = r'C:\path\to\directory'
start_date = '2023-01-01'  # Start date (inclusive) in YYYY-MM-DD format
end_date = '2023-12-31'    # End date (inclusive) in YYYY-MM-DD format

files_found = find_files_in_date_range(directory_to_search, start_date, end_date)

# Print the list of found files
for file in files_found:
    print(file)
```

### Key Points:
1. **Parameters**:
   - `directory`: The directory you want to search.
   - `start_date` and `end_date`: The date range in the format `YYYY-MM-DD`.

2. **How it Works**:
   - The script walks through the directory (including subdirectories) using `os.walk()`.
   - For each file, it retrieves the modification time using `os.path.getmtime()`.
   - It compares the file’s modification time with the specified date range.

3. **Example**: Update `directory_to_search`, `start_date`, and `end_date` with your specific values.

This script will print the full paths of all files that were modified within the given date range.

To search for files within a date range using Access VBA, you can utilize the `FileSystemObject` to iterate through the files in a folder and filter them by their modification date. Below is an example of an Access VBA script that searches for files within a specific date range.

### VBA Code:

```vba
Option Compare Database
Option Explicit

' Add a reference to "Microsoft Scripting Runtime" under Tools -> References for FileSystemObject

Sub FindFilesInDateRange()

    ' Define folder path and date range
    Dim folderPath As String
    Dim startDate As Date
    Dim endDate As Date
    
    folderPath = "C:\path\to\directory" ' Set your folder path here
    startDate = #1/1/2023# ' Set your start date
    endDate = #12/31/2023# ' Set your end date
    
    ' Create FileSystemObject
    Dim fso As Object
    Set fso = CreateObject("Scripting.FileSystemObject")
    
    ' Check if the folder exists
    If fso.FolderExists(folderPath) Then
        Dim folder As Object
        Dim file As Object
        
        Set folder = fso.GetFolder(folderPath)
        
        ' Loop through each file in the folder
        For Each file In folder.Files
            
            ' Check the file's last modified date
            If file.DateLastModified >= startDate And file.DateLastModified <= endDate Then
                Debug.Print "File: " & file.Name & " - Modified on: " & file.DateLastModified
            End If
            
        Next file
        
    Else
        MsgBox "The folder does not exist.", vbExclamation
    End If
    
    ' Clean up
    Set fso = Nothing
    Set folder = Nothing
    Set file = Nothing
    
End Sub
```

### Explanation:

1. **Variables**:
   - `folderPath`: Set this to the path of the folder you want to search.
   - `startDate` and `endDate`: Define the date range (inclusive) in `MM/DD/YYYY` format.

2. **How it Works**:
   - The script uses `FileSystemObject` to access the files in the specified folder.
   - It loops through all files in the folder and checks each file's `DateLastModified`.
   - If the file's modification date falls within the specified range, it prints the file's name and modification date to the Immediate Window (`Ctrl + G` to view it).

3. **Add Reference**:
   - You need to add a reference to "Microsoft Scripting Runtime" in your Access VBA environment. To do this, go to **Tools** > **References**, then check **Microsoft Scripting Runtime**.

4. **Output**:
   - Files that meet the date criteria will be printed in the Immediate Window.

You can modify the `folderPath`, `startDate`, and `endDate` variables to suit your needs.
