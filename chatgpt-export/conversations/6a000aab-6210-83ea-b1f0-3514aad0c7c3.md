# 🟢 STEP 2 — Google Apps Script (core system)

Open:

Paste this:

```javascript
function addLead(name, address, source, phone, email, notes) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("GTA_LEADS");
  
  // prevent duplicates by address
  var data = sheet.getDataRange().getValues();
  for (var i = 1; i < data.length; i++) {
    if (data[i][1] == address) {
      return "Duplicate found - skipped";
    }
  }

  sheet.appendRow([
    name,
    address,
    source,
    phone,
    email,
    "New Lead",
    notes,
    new Date()
  ]);

  return "Lead added successfully";
}
```
