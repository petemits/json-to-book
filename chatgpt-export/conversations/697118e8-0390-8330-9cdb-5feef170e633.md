**What Puri Legal Services Does:**

✔ Lower long-term insurance impact

## 🔧 NLP ENTITY EXTRACTION (PYTHON)

```python
import spacy

nlp = spacy.load("en_core_web_sm")

def extract_entities(text):
    doc = nlp(text)
    entities = {
        "persons": [],
        "locations": [],
        "dates": [],
        "nouns": [],
        "subjects": []
    }

    for ent in doc.ents:
        if ent.label_ == "PERSON":
            entities["persons"].append(ent.text)
        elif ent.label_ in ["GPE", "LOC"]:
            entities["locations"].append(ent.text)
        elif ent.label_ == "DATE":
            entities["dates"].append(ent.text)

    for token in doc:
        if token.dep_ == "nsubj":
            entities["subjects"].append(token.text)
        if token.pos_ == "NOUN":
            entities["nouns"].append(token.text)

    return entities
```
