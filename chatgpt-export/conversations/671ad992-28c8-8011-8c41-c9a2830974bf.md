### Step 1: Install FFmpeg
If you don’t already have FFmpeg installed, you can download it from [FFmpeg's official website](https://ffmpeg.org/download.html). Follow the installation instructions for your operating system.

### Step 2: Split the Video into Parts
Assuming the video is about the same length as the file size distribution, you can use FFmpeg to divide it evenly into four parts. Let’s say the total duration is 40 seconds. You can split it into four 10-second parts (adjust according to your video's length).

Use this command for each split (assuming a 40-second video):

```bash
ffmpeg -i your-video.mp4 -ss 0 -t 10 -c copy part1.mp4
ffmpeg -i your-video.mp4 -ss 10 -t 10 -c copy part2.mp4
ffmpeg -i your-video.mp4 -ss 20 -t 10 -c copy part3.mp4
ffmpeg -i your-video.mp4 -ss 30 -t 10 -c copy part4.mp4
```

Explanation:
- `-i your-video.mp4`: The input video file.
- `-ss <start time>`: The starting point of each segment (in seconds).
- `-t <duration>`: The duration of each part (in seconds).
- `-c copy`: Copies without re-encoding, making the process fast.

Adjust the start times (`-ss`) and durations (`-t`) according to the exact length of your video.
