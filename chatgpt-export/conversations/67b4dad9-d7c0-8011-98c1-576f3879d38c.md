**Assistant:**

To set up Node.js in **Termux** within a **new directory**, follow these steps:

### **Step 1: Install Termux & Update Packages**
1. If you haven't already, install **Termux** from [F-Droid](https://f-droid.org/) or the Play Store.
2. Open Termux and update your packages:  
   ```sh
   pkg update && pkg upgrade -y
   ```

### **Step 2: Install Node.js**
Node.js is available in Termux. You can install it using:
```sh
pkg install nodejs -y
```
After installation, check the version:
```sh
node -v
npm -v  # To check if npm (Node Package Manager) is installed
```

### **Step 3: Create a New Directory & Navigate Into It**
Now, create a new project directory where you want to set up Node.js:
```sh
mkdir my-node-project
cd my-node-project
```

### **Step 4: Initialize a New Node.js Project**
Run the following command to initialize a Node.js project

---

---

**Assistant:**

Inside your new directory (`my-node-project`), initialize a new Node.js project by running:  

```sh
npm init -y
```
This will create a `package.json` file with default settings.

---

### **Step 5: Create a Simple Node.js Script**
Now, create a basic Node.js script:  

```sh
nano index.js
```
Inside `index.js`, add the following code:  

```js
console.log("Hello from Node.js in Termux!");
```
Save and exit (`CTRL + X`, then `Y`, then `Enter`).

---

### **Step 6: Run the Node.js Script**
Execute the script with:  

```sh
node index.js
```
If everything is set up correctly, you should see:  
```
Hello from Node.js in Termux!
```

---

### **Step 7: Install Additional Packages (Optional)**
You can install npm packages like Express:  

```sh
npm install express
```

Check installed packages with:  

```sh
npm list --depth=0
```

---

Now, your **Node.js environment** is successfully set up in **Termux**! Let me know if you need further help.
