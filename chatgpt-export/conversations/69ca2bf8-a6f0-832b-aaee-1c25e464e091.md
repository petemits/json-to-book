## 🔹 How to fix it

### 1️⃣ Make sure Node.js and npm are installed/up-to-date

```bash id="jco59e"

```

```bash id="i9bk6s"
node -v
npm -v
```

- Node.js >= 18 recommended

---

### 2️⃣ Increase memory for npm (optional but helps)

```bash id="rj6v6c"
export NODE_OPTIONS=--max_old_space_size=4096
```

- This allows npm to use up to 4GB RAM  
- Then retry install


```bash id="cyrf3f"
sudo mkswap /swapfile
```

- Then retry the OpenClaw install
