# 4) Configure WebRTC + SIP trunk + TLS certs (summary)
- WebRTC requires Asterisk to serve an HTTPS WebSocket (wss) endpoint and valid TLS certificate (Let's Encrypt ideally, but inside Android this is messy; you can use a public hostname with a cert or a self-signed cert with browser trust). For local testing, use insecure flags, but for production get valid certs.
- SIP trunk: configure your SIP provider (username/password) in `pjsip.conf` and set inbound to an extension/IVR.
- For inbound PSTN -> SIP provider -> Asterisk, you must ensure the SIP provider can reach your device (NAT). Since Android is usually behind cellular NAT or Wi-Fi router NAT, recommend either:
  - Use SIP provider that allows client registration (Asterisk registers to provider) — works behind NAT.  
  - Use a VPS as a relay (SIP proxy) to avoid tricky NAT on Android.

# 5) Dialplan + AI webhook flow (concrete example)
Goal: incoming call → play greeting → bridge to AI conversation (speech to text -> AI -> text to speech returned) → hang up or transfer.

We’ll use Asterisk’s AGI or an HTTP hook to a Flask AI server which handles TTS/STT and responds.

### pjsip.conf (minimal)
Create `/etc/asterisk/pjsip.conf` with a basic transport and a local phone:

```ini
[transport-udp]
type=transport
protocol=udp
bind=0.0.0.0

[6001]
type=endpoint
context=from-internal
disallow=all
allow=ulaw
auth=6001-auth
aors=6001

[6001-auth]
type=auth
auth_type=userpass
password=superpass
username=6001

[6001]
type=aor
max_contacts=1
```

(You’ll add your SIP trunk provider section as `auth` + `endpoint` for provider.)

### extensions.conf (dialplan)
Create `/etc/asterisk/extensions.conf`:

```asterisk
[from-pstn]
exten => _X.,1,NoOp(Incoming PSTN call)
 same => n,Answer()
 same => n,Set(CALLID=${CALLERID(num)})
 same => n,Playback(hello)         ; basic greeting
 same => n,Set(AGENT_SESSION=${UNIQUEID})
 ; send to AI webhook - bridge in background using chan_agi or call file to AGI script
 same => n,AGI(/usr/local/bin/agi_ai_bridge.py)
 same => n,Hangup()

[from-internal]
exten => 100,1,NoOp(Internal extension)
 same => n,Answer()
 same => n,Playback(hello)
 same => n,Hangup()
```

### AGI script (Python) — `/usr/local/bin/agi_ai_bridge.py`

```python

# instead, recommended: use MixMonitor in dialplan: MixMonitor(/tmp/${UNIQUEID}.wav,b)
# then this AGI should wait until recording exists.

# data should have 'tts' as url or base64 audio

    import openai
    openai.api_key = OPENAI_KEY
    resp = openai.ChatCompletion.create(
        model="gpt-4o-mini",
        messages=[{"role":"user","content":prompt}],
        max_tokens=200
    )
    return resp.choices[0].message.content

@app.route('/ai_converse', methods=['POST'])
def converse():
    f = request.files['file']
    fd, path = tempfile.mkstemp(suffix='.wav')
    f.save(path)
    text = stt_from_wav(path)
    ai_reply = ask_ai(text)
    # TTS
    tts = gTTS(ai_reply)
    tts_path = path.replace('.wav','_reply.mp3')
    tts.save(tts_path)
    return jsonify({'transcript': text, 'reply': ai_reply, 'tts': f'http://{request.host}/tts/{os.path.basename(tts_path)}'})

@app.route('/tts/<name>')
def serve_tts(name):
    tts_path = os.path.join(tempfile.gettempdir(), name)
    return send_file(tts_path, mimetype='audio/mpeg')

if __name__ == '__main__':
    app.run(host='0.0.0.0', port=5000)
```

# dashboard_backend.py (very simplified)
from flask import Flask
from flask_socketio import SocketIO
import socket, threading

app = Flask(__name__)
socketio = SocketIO(app, cors_allowed_origins='*')

def ami_listener():
    s = socket.socket()
    s.connect(('127.0.0.1', 5038))  # AMI
    s.send(b'Action: Login\r\nUsername: admin\r\nSecret: your_ami_secret\r\n\r\n')
    while True:
        data = s.recv(4096).decode()
        # parse events (very simplified)
        if 'Event: Newchannel' in data:
            socketio.emit('event', {'raw': data})

threading.Thread(target=ami_listener, daemon=True).start()

@app.route('/')
def index():
    return 'Dashboard backend running'

if __name__ == '__main__':
    socketio.run(app, host='0.0.0.0', port=8000)

# 10) NAT, security, and reliability caveats
- Running a PBX on Android phone is great for prototyping, but:
  - Battery/thermal and network flakiness are real. Phone may suspend processes on low RAM or backgrounding.
  - PSTN providers often require stable public IP/ports. Cellular networks often block SIP or NAT, so use a SIP provider that supports client registration or use a VPS relay.
  - Use TLS for signalling and SRTP for media when exposing to the Internet. Use fail2ban-like protections on the PBX.
  - Logs, backups, and monitoring should be set up if you depend on this for real customers.

## 🔹 What is a **VPS**?
**VPS = Virtual Private Server.**

It’s like renting a **computer that lives in the cloud**, instead of sitting on your desk or phone.  

- A hosting company takes a big physical server.  
- They split it into multiple **virtual machines** using virtualization (like Proxmox, VMware, etc.).  
- Each slice is called a **VPS**.  
- You get full root (administrator) access, like having your own Linux or Windows server, but you only pay for your slice.

---

## 🔹 How a VPS compares
- **Your Android phone** = your personal computer in your pocket.  
- **VPS** = your rented computer on the internet that runs 24/7, doesn’t depend on your phone’s battery, and has a public IP address.  

---

## 🔹 What you can do with a VPS
- Run **PBX software** (like 3CX or Asterisk) so people can call your number and reach your AI agent.  
- Host **websites, dashboards, or APIs**.  
- Run **AI services** (chatbots, voice agents, data analyzers).  
- Store files or backups.  
- Test code or projects that need to be online all the time.  

---

## 🔹 Why use a VPS instead of Android
- **Always online** → no battery issues.  
- **Public IP** → can connect easily from outside (your phone usually sits behind NAT/firewall).  
- **Better stability** → runs on server hardware with guaranteed uptime.  
- **Scalable** → upgrade CPU, RAM, storage when needed.  

---

## 🔹 Free & cheap VPS examples
- **Oracle Cloud Always Free** → 2 VMs (up to 4GB RAM each).  
- **AWS / Google / Azure Free Tier** → 1 VM free for 12 months.  
- **Vultr / DigitalOcean / Linode** → start from ~$5/month.
