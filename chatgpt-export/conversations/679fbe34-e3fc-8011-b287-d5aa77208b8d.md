# List download files Termux
*2025-02-02*

**User:**

Show all of my download files termux

---

**Assistant:**

In Termux, you can list all your downloaded files using the following command:  

```sh
ls ~/storage/downloads
```

If you haven't set up storage access for Termux, first run:  

```sh
termux-setup-storage
```

Then, try listing the files again. Let me know if you need more help!
