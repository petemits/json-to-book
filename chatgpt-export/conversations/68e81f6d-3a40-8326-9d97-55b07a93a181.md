# Option A — Docker (recommended)
1. Install Docker / Docker Compose (Docker Desktop on Windows/macOS).  
   (Get Docker from docker.com). citeturn0search13  
2. Create a directory for n8n data, e.g. `~/n8n` and a `docker-compose.yml` inside it.

Copy/paste this `docker-compose.yml` (example — stores data locally and exposes port `5678`):

```yaml
version: "3.7"

services:
  n8n:
    image: n8nio/n8n:latest
    restart: unless-stopped
    environment:
      - GENERIC_TIMEZONE=America/Toronto
      # For local testing you can enable the tunnel (unsafe for production) or configure a reverse proxy/HTTPS
      # - N8N_TUNNEL_SUBDOMAIN=your-subdomain  # optional (if you have a tunnel provider)
    volumes:
      - ./n8n-data:/home/node/.n8n
    ports:
      - "5678:5678"
```

3. Start it:
```bash
cd ~/n8n
docker compose up -d
```
4. Open the UI at `http://localhost:5678`. Data lives in `./n8n-data` so updates/restarts keep your workflows. To upgrade: `docker pull n8nio/n8n:latest && docker compose down && docker compose up -d`. citeturn0search6turn1search1

**Notes & production tips**
- For production use a proper DB (Postgres) instead of the default SQLite, and put n8n behind an HTTPS reverse proxy (NGINX / Caddy) and add authentication. The docs cover recommended env variables and production configs. citeturn0search5turn1search3

### 🧩 Step 3: Add global npm binaries to PATH
After install, Termux sometimes doesn’t see global commands automatically.  
Check where npm put n8n:

```bash
npm root -g
```

You’ll get something like:
```
/data/data/com.termux/files/usr/lib/node_modules
```

Global binaries (like `n8n`) are in:
```
/data/data/com.termux/files/usr/bin
```
or sometimes:
```
/data/data/com.termux/files/usr/lib/node_modules/.bin
```

Let’s make sure Termux knows where to look:

```bash
export PATH=$PATH:$(npm bin -g)
```

If you want to make that permanent, append it to your `.bashrc` or `.zshrc`:
```bash
echo 'export PATH=$PATH:$(npm bin -g)' >> ~/.bashrc
```

Every flow in Node-RED starts with something — the Inject node is that **starting point**.

> **Inject node** = faucet handle (turns on the water)

If you get errors about `sqlite3` or `node-gyp`, make sure your system has:

**Windows:**
```bash
npm install --global --production windows-build-tools
```

**Ubuntu/Debian:**
```bash
sudo apt install -y build-essential python3
```

**macOS:**
```bash
xcode-select --install
```

Then re-run the n8n install command.

## 💾 STEP 4 — (Optional) Run in the Background

You can use **pm2** (a process manager) to keep n8n running 24/7:

```bash
npm install -g pm2
pm2 start n8n --name n8n
pm2 save
pm2 startup
```

That makes n8n auto-start after reboot.
