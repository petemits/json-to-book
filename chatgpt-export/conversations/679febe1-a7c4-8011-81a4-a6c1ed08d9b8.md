# Termux Directory Locations
*2025-02-02*

**User:**

Where does my directory store in termux

---

**Assistant:**

In Termux, your home directory is stored at:  

```
/data/data/com.termux/files/home
```

### Common Termux Directories:
- **Home Directory:** `/data/data/com.termux/files/home/`  
  - This is your main working directory where you can store files, scripts, and projects.  
- **Shared Storage (Internal Storage):** `/storage/emulated/0/`  
  - You need to grant Termux access to shared storage using:  
    ```sh
    termux-setup-storage
    ```
    After granting permission, Termux creates a symlink at:
    ```sh
    ~/storage
    ```
    which includes:
    - **~/storage/downloads** → `/storage/emulated/0/Download/`
    - **~/storage/dcim** → `/storage/emulated/0/DCIM/`
    - **~/storage/pictures** → `/storage/emulated/0/Pictures/`
    - **~/storage/music** → `/storage/emulated/0/Music/`
    - **~/storage/movies** → `/storage/emulated/0/Movies/`
    - **~/storage/shared** → `/storage/emulated/0/`

**User:**

How do I access directories on my phone

---

**Assistant:**

You can access directories on your phone using Termux in the following ways:  

### **1. Accessing Termux Home Directory**  
Your default working directory in Termux is:  
```sh
cd ~
```
To list files in your home directory:  
```sh
ls
```

### **2. Accessing Internal Storage (Shared Storage)**
To access your phone's internal storage, you need to grant permission:  
```sh
termux-setup-storage
```
This creates a **~/storage/** folder with symlinks to common directories:  
```sh
cd ~/storage
ls
```
You will see:  
- **downloads** → `/storage/emulated/0/Download/`
- **shared** → `/storage/emulated/0/`
- **dcim, music, movies, pictures** → Corresponding media folders  

To enter the **Download** folder:  
```sh
cd ~/storage/downloads
ls
```

### **3. Accessing SD Card (If Available)**
If your phone has an SD card, it is usually mounted at:  
```sh
cd /storage/
ls
```
You might see a folder like **`1234-5678/`** (varies by device).  
To access it:  
```sh
cd /storage/1234-5678/
ls
```

### **4. Using GUI File Manager**  
If you prefer a graphical way:  
- Open your **File Manager** app  
- Navigate to **Internal Storage** or **SD Card**  
- Find **Android > data > com.termux > files > home** (this is Termux’s home directory)
