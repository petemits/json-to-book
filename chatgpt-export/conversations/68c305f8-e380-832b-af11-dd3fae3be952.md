The **Sourcegraph Instance URL** depends on where you are using Sourcegraph:

     ```
     https://sourcegraph.com

     ```
     https://sourcegraph.mycompany.com

   - Your instance URL will be the local address where you’re hosting it, often:  
     ```
     http://localhost:7080
     ```  
   - Or if you mapped it differently, the custom port/domain you set up.

In both cases, you can connect to GPT (OpenAI’s API) by making HTTP requests to the API and passing your API key. Since GPT doesn’t come as a built-in library for Visual Basic, you integrate it using **HTTP requests (REST API)**.

---

## ✅ Steps to Add GPT to Visual Basic (general approach)

### 1. Get an OpenAI API Key
- Sign up at [https://platform.openai.com](https://platform.openai.com).
- Go to **API Keys** in your account.
- Create a new **secret key**.

---

### 2. Make an API Call from Visual Basic
You need to send an HTTP POST request with JSON to the GPT endpoint.

### Example: VB.NET (Windows Forms or Console App)
```vbnet
Imports System.Net.Http
Imports System.Text
Imports System.Threading.Tasks

Module GPTExample
    Async Function CallGPT() As Task
        Dim apiKey As String = "YOUR_API_KEY"
        Dim apiUrl As String = "https://api.openai.com/v1/chat/completions"

        Using client As New HttpClient()
            client.DefaultRequestHeaders.Add("Authorization", "Bearer " & apiKey)

            Dim json As String = "{
                ""model"": ""gpt-4o-mini"",
                ""messages"": [
                    {""role"": ""user"", ""content"": ""Hello GPT from Visual Basic!""}
                ]
            }"

            Dim content As New StringContent(json, Encoding.UTF8, "application/json")
            Dim response As HttpResponseMessage = Await client.PostAsync(apiUrl, content)
            Dim responseString As String = Await response.Content.ReadAsStringAsync()

            Console.WriteLine(responseString)
        End Using
    End Function

    Sub Main()
        CallGPT().Wait()
    End Sub
End Module
```

---

### 3. If You Mean VBA (Excel / Word)

That requires **enabling references** to `Microsoft XML v6.0` or `WinHTTP Services`.

---

### 4. Security Note
- Never hardcode your API key in code you share.
- Store it securely (e.g., environment variables).

## 🔹 Step 3. Add Code to Call GPT
Here’s a minimal working example:

```vbnet
Imports System
Imports System.Net.Http
Imports System.Text
Imports System.Threading.Tasks

Module GPTExample

    Async Function CallGPT() As Task
        Dim apiKey As String = "YOUR_API_KEY" ' 🔑 Replace with your actual API key
        Dim apiUrl As String = "https://api.openai.com/v1/chat/completions"

        Using client As New HttpClient()
            client.DefaultRequestHeaders.Add("Authorization", "Bearer " & apiKey)

            ' JSON body for GPT request
            Dim json As String = "{
                ""model"": ""gpt-4o-mini"",
                ""messages"": [
                    {""role"": ""user"", ""content"": ""Hello GPT from Visual Basic in Visual Studio!""}
                ]
            }"

            Dim content As New StringContent(json, Encoding.UTF8, "application/json")
            Dim response As HttpResponseMessage = Await client.PostAsync(apiUrl, content)
            Dim responseString As String = Await response.Content.ReadAsStringAsync()

            Console.WriteLine(responseString) ' Print GPT response JSON
        End Using
    End Function

    Sub Main()
        CallGPT().Wait() ' Run the async function
        Console.ReadLine()
    End Sub

End Module
```

---

## 🔹 Step 4. Run It
- Press **F5** to run.  
- You’ll see GPT’s raw JSON response in the console.  

---

## 🔹 Step 5. Parse the Response (Optional)
The GPT response is JSON. To make it cleaner, you can parse it with `System.Text.Json`:

```vbnet
Imports System.Text.Json

' Inside CallGPT, after responseString:
Dim jsonDoc = JsonDocument.Parse(responseString)
Dim content = jsonDoc.RootElement.GetProperty("choices")(0).GetProperty("message").GetProperty("content").GetString()
Console.WriteLine("GPT says: " & content)
```
