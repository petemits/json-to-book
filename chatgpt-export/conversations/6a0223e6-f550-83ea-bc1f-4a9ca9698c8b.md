You can check your **computer specs directly from Command Prompt or PowerShell** using a few built-in commands.

## 🧾 1. Full system details (best simple option)
Open **Command Prompt (CMD)** and type:

```
systeminfo
```

This shows:
- Computer model
- Windows version
- RAM
- Processor
- BIOS info
- Network info

---

## ⚙️ 2. Quick CPU + RAM + system summary (PowerShell)
Open **PowerShell** and run:

```
Get-ComputerInfo
```

If that’s too long, use a cleaner version:

```
Get-ComputerInfo | Select-Object CsName, OsName, OsArchitecture, CsTotalPhysicalMemory, CsProcessors
```

---

## 🧠 3. CPU details only
In CMD or PowerShell:

```
wmic cpu get name,NumberOfCores,NumberOfLogicalProcessors
```

---

## 💾 4. RAM details only
```
wmic memorychip get capacity,speed,manufacturer
```

---

## 🖥️ 5. GPU (graphics card)
```
wmic path win32_VideoController get name
```

---

## 🧰 6. Full diagnostic tool (GUI but launched from shell)
```
dxdiag
```

This opens a window with:
- CPU
- RAM
- GPU
- Display info
- Drivers

---

## 👍 Quick recommendation
If you only remember one:
- 👉 `systeminfo` = full overview  
- 👉 `dxdiag` = easiest visual report

**Assistant:**

You can find files on your computer using **Command Prompt (CMD)** or **PowerShell**. Here are the most useful ways:

---

## 📁 1. Search files using CMD (basic)

### Search inside a drive
```bash
dir C:\filename.ext /s
```

Example:
```bash
dir C:\report.pdf /s
```

- `/s` = searches all folders inside C: drive

---

## 🔍 2. Search by file type (all PDFs, for example)
```bash
dir C:\*.pdf /s
```

Or images:
```bash
dir C:\*.jpg /s
```

---

## ⚡ 3. Faster search using PowerShell (recommended)

### Find a file by name:
```powershell
Get-ChildItem -Path C:\ -Recurse -Filter "filename.ext"
```

Example:
```powershell
Get-ChildItem -Path C:\ -Recurse -Filter "notes.txt"
```

---

## 📂 4. Search partial names (very useful)
```powershell
Get-ChildItem -Path C:\ -Recurse -Include "*report*"
```

This finds anything with “report” in the name.

---

## 🚀 5. Search only in a folder (faster)
Instead of whole C: drive:

```powershell
Get-ChildItem -Path C:\Users\YourName\Documents -Recurse -Filter "*.pdf"
```

---

## 🧠 Tips
- Searching whole `C:\` can be slow
- Better to search inside **Documents / Downloads**
- Use quotes if file names have spaces:
  ```powershell
  "my file.txt"
  ```
