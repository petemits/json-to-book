Ah — that error is very common when using **Node-RED to fetch Google Sheets via the “gviz/tq?tqx=out:json” URL**. The issue is:

1. The **HTTP Request node returns a string**, not a proper JSON object.  
2. The returned string from Google Sheets is wrapped like:

```js
/**/ google.visualization.Query.setResponse(...);
```

Node-RED tries to parse it as JSON and fails → `"JSON parse error"`.  
Then your **Process Data node fails** because `msg.payload` is not an object.

---

## ✅ Fix

You need to **strip the Google wrapper** and parse JSON before passing to the next node.

### Option 1: Use a **Function node after HTTP request**:

```javascript
// Remove Google wrapper
let jsonText = msg.payload;

// Remove prefix and suffix
jsonText = jsonText.replace(/^.*?setResponse\(/, '').replace(/\);$/, '');

// Parse JSON
msg.payload = JSON.parse(jsonText);

// Now msg.payload.table.rows contains your sheet data
return msg;
```
