## 1️⃣ Is there PowerShell on Android?
**Yes, but unofficially.**

### Best working options:
#### ✅ **PowerShell via Termux (recommended)**
Termux is a Linux terminal app for Android.

**Flow:**
- Android → Termux → Linux → PowerShell Core (`pwsh`)
- You write **real PowerShell scripts**

**What it can do well**
- Loops
- Files
- Lists of numbers
- APIs
- Automation logic

**What it cannot do natively**
- Send SMS directly
- Control phone UI
- Access contacts without extra Android permissions

## 2️⃣ Installing PowerShell on Android (Termux)
High-level steps (no fluff):

1. Install **Termux** (from F-Droid, not Play Store)
2. Open Termux and run:
```bash
pkg update && pkg upgrade
pkg install wget tar
pkg install powershell
```
3. Start PowerShell:
```bash
pwsh
```

Now you’re inside PowerShell on Android ✅

## 3️⃣ Auto-listing numbers one by one (PowerShell logic)
This part is **easy and fully supported**.

### Example: generate numbers one by one
```powershell
$numbers = 1000000000..1000000010

foreach ($num in $numbers) {
    Write-Host "Processing number: $num"
    Start-Sleep -Seconds 2
}
```

This works perfectly on Android PowerShell.

## 4️⃣ Sending those numbers via mobile phone ❗
Here’s the **important truth**:

### ❌ PowerShell alone **cannot send SMS on Android**
Android blocks direct SMS access unless:
- You’re a system app
- OR using Android APIs
- OR using automation tools

### ✅ What *does* work (realistic options)

- Twilio

PowerShell sends numbers → API sends messages

Example logic:
```powershell

```

✔️ Clean  
✔️ Legal  
✔️ Reliable

#### Option B — **PowerShell + Termux SMS**
Termux has an **SMS add-on** (user permission required).

Install:
```bash
pkg install termux-api
```

```bash
termux-sms-send -n 1234567890 "Hello"
```

From PowerShell:
```powershell
$num = "1234567890"
$message = "Hello from PowerShell"
bash -c "termux-sms-send -n $num '$message'"
```

⚠️ Android permission pop-ups  
⚠️ May break on newer Android versions

- A button is pressed
- Time is 10:00 AM
- Incoming call
- File changes
- App opens
- You tap a widget

> “When THIS happens…”

---

### 2️⃣ **Tasks = What Happens**
A **Task** is a list of actions Tasker runs **in order**.

Examples of actions:
- Make a phone call
- Wait 10 seconds
- Speak text (TTS)
- Read a file
- Write a file
- Set variables
- Vibrate
- Send notification

> “…DO this, then this, then this.”

---

### 3️⃣ **Actions = Steps**
Actions are the individual instructions inside a task.

Example task:
1. Call a number  
2. Wait  
3. Speak message  
4. End call  
5. Save result

## 🧠 Simple Example (Plain English)
