Here’s a simple implementation of a `wc` (word count) tool in JavaScript that counts the number of lines, words, and characters in a given string. This mimics the functionality of the Unix `wc` command.

```javascript
// wc (word count) tool in JavaScript
function wc(text) {
  const lines = text.split('\n').length;
  const words = text.trim().split(/\s+/).length;
  const characters = text.length;

  return {
    lines: lines,
    words: words,
    characters: characters
  };
}

// Example usage
const sampleText = `This is an example text.
It spans multiple lines.
It also contains multiple words and characters.`;

const result = wc(sampleText);
console.log(`Lines: ${result.lines}`);
console.log(`Words: ${result.words}`);
console.log(`Characters: ${result.characters}`);
```

### Explanation:
- **Lines**: We split the text by `\n` (newlines) to get the number of lines.
- **Words**: We use `trim()` to remove leading/trailing spaces and split the text by whitespace (`\s+` regex) to count the words.
- **Characters**: This simply counts the number of characters in the string using `.length`.

You can easily run this in a browser or Node.js environment.

Here’s an example of how you can create a simple mock server in JavaScript using Node.js and Express. The server will have an endpoint that accepts text input and returns the word count (`wc`) results (lines, words, and characters).

### Steps:
1. First, install Node.js if you haven’t already.
2. Install Express using `npm`.

```bash
npm init -y
npm install express
```

### Code for Mock Server (`server.js`):

```javascript
const express = require('express');
const bodyParser = require('body-parser');

const app = express();
const PORT = 3000;

// Middleware to parse JSON bodies
app.use(bodyParser.json());

// wc (word count) function
function wc(text) {
  const lines = text.split('\n').length;
  const words = text.trim().split(/\s+/).length;
  const characters = text.length;

  return {
    lines: lines,
    words: words,
    characters: characters
  };
}

// Endpoint to handle POST request for word count
app.post('/wc', (req, res) => {
  const text = req.body.text;
  if (!text) {
    return res.status(400).send({ error: 'Text is required' });
  }

  const result = wc(text);
  res.send(result);
});

// Start the server
app.listen(PORT, () => {
  console.log(`Server is running on http://localhost:${PORT}`);
});
```

### Sample Usage:

1. Start the server:
   ```bash
   node server.js
   ```

2. You can test the server using a tool like `curl`, Postman, or from your browser (using fetch):

- **Using `curl`:**

```bash
curl -X POST http://localhost:3000/wc -H "Content-Type: application/json" -d '{"text": "This is a test text.\nIt has two lines."}'
```

- **Response:**

```json
{
  "lines": 2,
  "words": 7,
  "characters": 36
}
```

3. **Using Fetch (browser console):**

```javascript
fetch('http://localhost:3000/wc', {
  method: 'POST',
  headers: {
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ text: 'This is a test text.\nIt has two lines.' })
})
  .then(response => response.json())
  .then(data => console.log(data));
```

### Explanation:
- **Server Setup**: We use Express to create a simple web server.
- **POST `/wc` endpoint**: Accepts a JSON body with `text` and returns the word count (lines, words, characters).
- **wc function**: Calculates lines, words, and characters from the text input.
